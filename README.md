# Optimization Dynamics and Generalization in Deep Neural Networks

A reproducible empirical benchmark studying how optimizer choice affects convergence, gradient dynamics, and generalization on controlled synthetic classification tasks.

## Research question
How do SGD, Momentum SGD, AdamW, and L-BFGS differ in optimization behavior and test performance as dataset noise changes?

## Scope
This is an empirical benchmark, not a new optimizer or a theoretical convergence proof. Conclusions must be drawn from generated results; no winner is claimed in advance.

## Experimental protocol
- Two-moons binary classification, with configurable noise.
- Fixed multilayer perceptron architecture.
- Four optimizers: SGD, Momentum, AdamW, L-BFGS.
- Multiple random seeds and noise levels.
- Metrics: train/test loss and accuracy, gradient norm, parameter update norm, epoch time.
- Outputs: run-level CSV, mean/std summary CSV, plots, experiment metadata.
- Preprocessing is fitted on training data only.

**Fairness note:** L-BFGS uses full-batch closure-based steps; the other optimizers use mini-batches. Epochs therefore do not represent equal gradient-evaluation budgets. Interpret time and update protocols alongside epoch curves.

## Run
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python run_experiment.py
```
Run tests with `pytest -q`. Edit `config.json` to change seeds, noise levels, epochs, and learning rates.

## Limitations
Two-moons is a small synthetic benchmark, not a substitute for large-scale real-world deep learning. Hyperparameters influence outcomes. This repository makes no claim of a novel optimization algorithm or theoretical result. Report only results actually generated by running the code.
